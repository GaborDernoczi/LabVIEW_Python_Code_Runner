# LabVIEW Python Code Runner

A minimal example showing how to call a Python function from LabVIEW using the built-in
**Python Node** (*Connectivity » Python* palette).

<img width="1576" height="1265" alt="LabVIEW VI using the Python Node" src="https://github-playground.int.automotive-wan.com/user-attachments/assets/59a57dc1-ddc7-4635-bdec-c9c0d2bb0fb3" />

## Requirements

| Component | Version |
| --- | --- |
| LabVIEW | 2026 Q1 |
| Python | 3.12.0 |

LabVIEW 2026 Q1 officially supports Python 3.12 according to NI's
[LabVIEW–Python compatibility table](https://knowledge.ni.com/KnowledgeArticleDetails?id=kA00Z0000015C6tSAE&l=en-MY).

> **Important:** LabVIEW and Python must have the same architecture. A 32-bit
> LabVIEW installation can load only a 32-bit Python interpreter, while a 64-bit
> LabVIEW installation can load only a 64-bit Python interpreter. Python 3.12.0 is
> a supported choice for LabVIEW 2026 Q1.

## Files

| File | Description |
| --- | --- |
| `Python_LabVIEW.vi` | Opens a Python session, calls the function, and closes the session. |
| `Python_LabVIEW.py` | Python module containing the `LabVIEW()` function called by LabVIEW. |
| `Python_LabVIEW.lvproj` | LabVIEW project file, including a build specification for a stand-alone executable. |
| `Python_LabVIEW.aliases` | Project aliases file generated by LabVIEW. |

## How it works

The VI uses three nodes from the *Connectivity » Python* palette:

1. **Open Python Session** – specify Python version `3.12` and, if required, the
   full path to the Python DLL. It returns a Python session reference.
2. **Python Node** – provide the path to the Python module (`Python_LabVIEW.py`),
   the function name (`LabVIEW`), input parameters, and return type. The LabVIEW
   data type wired to the return terminal determines how the Python return value is converted.
3. **Close Python Session** – releases the interpreter and its resources.

The standard error-cluster wire between the nodes enforces execution order and
propagates errors.

## Usage

1. Install Python 3.12.0 with the same architecture as your LabVIEW installation.
2. Open `Python_LabVIEW.lvproj` in LabVIEW 2026 Q1.
3. Open `Python_LabVIEW.vi`.
4. In **Open Python Session**, select version `3.12`. If LabVIEW does not locate
   the interpreter automatically, provide the full path to `python312.dll`.
5. Verify that the module path on the block diagram points to `Python_LabVIEW.py`.
   Use a relative path or *Current VI's Path* so the VI also works after building.
6. Enter values for `Input1`, `Input2`, and `Input3` on the front panel, then run
   the VI. The indicator displays the sum returned by the Python function.

## Building an executable

The project contains a build specification named **Python_LabVIEW** that creates
`Application.exe` in `builds/NI_AB_PROJECTNAME/Python_LabVIEW`.

The `.py` file is not embedded in the executable automatically. Add it to the
build specification's *Always Included* items so it is copied next to the
executable, in the `data` directory. At run time, resolve its path from
*Application Directory*, for example.

## Troubleshooting

| Symptom | Cause / solution |
| --- | --- |
| Python fails to load | Python is not installed, the wrong version is selected, or the architectures do not match. Verify the Python 3.12 installation and matching architecture. |
| Module cannot be loaded | The `.py` file path is incorrect, or importing the module raises an error. |
| Function not found | The function name is misspelled, or the function is not defined at module level. |
| Type conversion error | A LabVIEW input or return-terminal data type does not match the Python value type. |
| Error while closing the session | Do not close a session while a Python Node is running. Use error wires to enforce execution order. |

## Notes

- Output from the Python function's `print()` goes to the process standard output,
  which is generally not visible in the LabVIEW IDE. Return a value instead when
  it needs to be displayed.
- A LabVIEW process can load only one Python interpreter version. Restart LabVIEW
  to switch to another version.
